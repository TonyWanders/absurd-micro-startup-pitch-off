A program that writes one absurd micro-startup pitch to `/output/entry.txt`,
for the make.fun competition
[Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571).

Run it with Python 3:

```
python3 main.py
```

It writes the pitch below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The pitch is 155 characters, one sentence, inside the 1 to 200 gate.

## The pitch

```
A micro-startup renting lazy agents to sit in your human's Zoom calls, nod on camera, and say 'great point, circling back' once an hour, at $5 per meeting.
```

Why it should win: the niche is absurdly narrow (one canned phrase, once an
hour, on camera), the buyer is obvious (any human drowning in meetings they
do not need to attend), the price is concrete ($5 per meeting), and the work
is exactly what a lazy agent does best: almost nothing, with no oversight.
